# BadBalanced
это сайт для кастомного режима 'BadBalanced' в Dota 2. создан в целях введения истории изменения
ссылка на проект:
https://steamcommunity.com/sharedfiles/filedetails/?id=3699416108

## 📋 Описание проекта

Сайт для отслеживания изменений героев и их скиллов в различных патчах игры. Система позволяет хранить информацию о патчах, героях, и их скиллах с возможностью отслеживания истории изменений.
